Конструктор приглашения

Выберите один из 38 стилей, подставьте свои данные и скачайте готовый HTML-файл — его можно сразу отправлять гостям или выкладывать на хостинг.

⚠️ Важно про даты. Автоматически надёжно заменяются: имена жениха и невесты, ссылка для RSVP, срок ответа, обратный отсчёт (таймер) и большинство текстовых упоминаний даты. Но в нескольких стилях дата продублирована крупной декоративной цифрой отдельно от названия месяца — после скачивания стоит один раз пролистать файл глазами и убедиться, что везде видна новая дата. Место проведения заменяется, только если совпадает с тем, что показано в поле «Текущее место» — иначе отредактируйте его вручную в скачанном файле.
Как это работает. Страница читает исходный файл выбранного стиля прямо из этой папки и подставляет ваши значения. Поэтому конструктор нужно открывать через сайт (обычный http/https-адрес, например GitHub Pages) — если открыть файл двойным кликом с диска, браузер может заблокировать чтение соседних файлов.
